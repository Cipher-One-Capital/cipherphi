# CipherPhi

Onchain zakat collection and redistribution on Stellar.

Donors calculate and pay their zakat into a pooled Soroban smart contract and
receive cryptographic proof, from the Stellar ledger, that funds reached
verified recipients. CipherPhi is the onchain layer for the Swiss Zakat
Foundation, an operating, audited Swiss foundation running zakat distribution
since 2020.

## Status

Pre-build. This repository holds the SCF Build (Open Track) submission
materials. Smart contract and app development begin at grant kickoff.
